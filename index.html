블로그 초안 생성기

주제만 넣으면 내 말투로 제목 3개 · 본문 · 요약표 · 이미지 프롬프트까지 한 번에 뽑아요.

1 제미나이 키 설정

키 없음

발급: Google AI Studio (aistudio.google.com) → Get API key (무료)

키는 이 브라우저에만 저장되고, 구글 API 호출에만 쓰여요.

2 글감 넣기

오늘 날짜 기준 시즌·생활 꿀팁 주제 5개를 추천해요 (실시간 웹 검색은 무료 키 제한으로 미지원)

✍️ 내 말투 예시(여기에 내가 쓴 글 붙여넣으면 그대로 따라 써요)

여기 적은 말끝·호흡·감정 표현을 그대로 따라 써요. 비워두면 기본 예시로 써요.

문제가 생겼어요

3 초안 결과

📝

주제만 넣고 초안 생성하기를 누르면
제목 3개부터 이미지 프롬프트까지 한 번에 나와요.

처음 한 번만 하면 되는 3단계
  1. 키 발급 — aistudio.google.com 접속 → 구글 로그인 → Get API key → 키 만들기 → 복사
  2. 키 붙여넣기 — 위 1번 칸에 붙여넣으면 이 브라우저에 자동 저장돼요 (다음부터는 안 넣어도 됨)
  3. 주제만 입력 → 초안 생성하기 → 다 나오면 📋 전체 복사 → 피클 채팅창에 그대로 붙여넣기

사진 파일은 여기서 만들어지지 않아요. 맨 아래 이미지 프롬프트를 복사해서 제미나이나 피클에게 넘기면 돼요.

💡 🔄 핫한 주제 5개는 오늘 날짜로 지금 시즌 주제를 뽑아 줘요(웹 검색이 아니라 모델의 시즌 감각이라 가격·일정은 메모에 적어 주세요). ✍️ 내 말투 예시는 한 번 붙여두면 그 말투 그대로 계속 써요.

키·말투 예시·오늘의 추천 주제는 이 브라우저(localStorage)에만 저장돼요 · AI 초안은 사실과 다를 수 있으니 가격·날짜는 한 번만 확인하고 발행해 주세요
